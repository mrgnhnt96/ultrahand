# Sources

The citation keys used in [principles.md](principles.md) and [presets.md](presets.md).
Platform guidelines are living documents; they were checked in November 2026.

## Platform guidelines

| Key | Source |
| --- | --- |
| HIG-IPADOS | Apple, *HIG: Designing for iPadOS* (viewing distance, input modes, minimise modals). https://developer.apple.com/design/human-interface-guidelines/designing-for-ipados |
| HIG-LAYOUT | Apple, *HIG: Layout* (size classes, not devices; same functionality at every size). https://developer.apple.com/design/human-interface-guidelines/layout |
| HIG-MULTI | Apple, *HIG: Multitasking* (full-screen and windowed apps; apps get no indication of the configuration). https://developer.apple.com/design/human-interface-guidelines/multitasking |
| HIG-WINDOWS | Apple, *HIG: Windows* (window controls at the toolbar's leading edge; multiple windows). https://developer.apple.com/design/human-interface-guidelines/windows |
| HIG-SPLIT | Apple, *HIG: Split views* (1/3 + 2/3 default, persistent selection, hidden panes, narrow widths). https://developer.apple.com/design/human-interface-guidelines/split-views |
| HIG-SIDEBARS | Apple, *HIG: Sidebars*. https://developer.apple.com/design/human-interface-guidelines/sidebars |
| HIG-TABS | Apple, *HIG: Tab bars* (iPad tab bar at the top, converts to a sidebar). https://developer.apple.com/design/human-interface-guidelines/tab-bars |
| HIG-MENUBAR | Apple, *HIG: The menu bar* (iPadOS menu bar). https://developer.apple.com/design/human-interface-guidelines/the-menu-bar |
| HIG-POINTER | Apple, *HIG: Pointing devices* (pointer effects, hover, I-beam, rectangle selection). https://developer.apple.com/design/human-interface-guidelines/pointing-devices |
| HIG-CONTEXT | Apple, *HIG: Context menus* (touch and hold or secondary click; relevant and few; every item also available elsewhere). https://developer.apple.com/design/human-interface-guidelines/context-menus |
| HIG-KEYBOARD | Apple, *HIG: Keyboards* (standard shortcuts, modifiers, Full Keyboard Access). https://developer.apple.com/design/human-interface-guidelines/keyboards |
| HIG-DND | Apple, *HIG: Drag and drop*. https://developer.apple.com/design/human-interface-guidelines/drag-and-drop |
| HIG-A11Y | Apple, *HIG: Accessibility* (44 × 44 pt targets, contrast). https://developer.apple.com/design/human-interface-guidelines/accessibility |
| AND-WSC | Android Developers, *Window size classes* (width: compact < 600, medium 600–839, expanded 840–1199, large 1200–1599, extra-large 1600+; height: compact < 480, medium 480–899, expanded 900+). https://developer.android.com/develop/ui/compose/layouts/adaptive/window-size-classes |
| AND-MW | Android Developers, *Support multi-window mode* (split screen, desktop windowing, Android 16 large-screen behaviour, minimum sizes, test checklist). https://developer.android.com/develop/ui/compose/layouts/adaptive/support-multi-window-mode |
| AND-CANON | Android Developers, *Canonical layouts* (list-detail, supporting pane, feed). https://developer.android.com/develop/ui/compose/layouts/adaptive/canonical-layouts |
| AND-NAV | Android Developers, *Build adaptive navigation* (bar vs rail vs drawer by window size). https://developer.android.com/develop/ui/compose/layouts/adaptive/build-adaptive-navigation |
| AND-QUAL | Android Developers, *Adaptive app quality guidelines* (tiers and reference test devices). https://developer.android.com/docs/quality-guidelines/adaptive-app-quality |
| AND-T2 | Android Developers, *Adaptive app quality, Tier 2: Adaptive optimized* (layouts, max widths, rails, keyboard, mouse, 48 dp targets). https://developer.android.com/docs/quality-guidelines/adaptive-app-quality/tier-2 |
| M3-CANON | Material Design 3, *Canonical layouts* and layout foundations. https://m3.material.io/foundations/layout/canonical-layouts/overview |

## Research

| Key | Source |
| --- | --- |
| NNG-IPAD | Jakob Nielsen, "iPad Usability: Year One", NN/g, 22 May 2011. Read–tap asymmetry (targets too small and close), hidden navigation, accidental touches, swipe ambiguity, shared devices. https://www.nngroup.com/articles/ipad-usability-year-one/ |
| HOOBER-TOUCH | Steven Hoober, "Design for Fingers, Touch, and People, Part 1", *UXmatters*, 6 Mar 2017. Includes tablet observations. People prefer to view and touch the centre; about 7 mm targets in the centre and 12 mm in the corners. https://www.uxmatters.com/mt/archives/2017/03/design-for-fingers-touch-and-people-part-1.php |
